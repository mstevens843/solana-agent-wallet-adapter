# @solana-agent-wallet-adapter/core

Protocol types and helpers shared by every package in the `solana-agent-wallet-adapter` monorepo. Defines the contract: `SigningRequest`, `ApprovalResource`, `WalletBackend`, `ProtocolError`.

If you're integrating an AI agent framework or building a new wallet backend, this is the only package you need to depend on directly.

See `spec/protocol.md` at the repo root for the full draft.
