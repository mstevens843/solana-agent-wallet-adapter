# @solana-agent-wallet-adapter/core

Protocol types and helpers shared by every package in the `solana-agent-wallet-adapter` monorepo. This package defines the signing contract: `SigningRequest`, `ApprovalResource`, `WalletBackend`, `ProtocolError`, and `SolanaSigningClient`.

If you're integrating an AI agent framework or building a new wallet backend, this is the only package you need to depend on directly.

See [`spec/protocol.md`](../../spec/protocol.md) for the full draft.
