# Agentic Brand Assets

This is the canonical folder for Agentic image assets.

Use these files for uploads and previews:

- `app-icon-512.png` - padded 512x512 app icon for Solana Mobile, web icons, desktop, and Android launcher previews.
- `saturn-source-cutout.png` - transparent UI brand mark for in-app/page logos.
- `banner-1200x600.png` - Solana Mobile banner.
- `editor-choice-1200x1200.png` - Editor's Choice square graphic.
- `social-og-1200x630.png` - web social preview image.
- `previews/` - Solana Mobile dApp preview images.

Android still needs generated copies in `apps/android-twa/app/src/main/res/drawable`.
The web app still needs generated copies in `apps/browser-demo/public/icons`.
Those platform folders are build outputs/copies, not the place to grab marketing assets.
