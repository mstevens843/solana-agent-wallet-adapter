# Private Agentic Docs

This folder is a local-only staging area for higher-context Agentic documentation. It is not intended for public GitHub until a separate redaction pass is complete.

## Purpose

Agentic has grown from a Solana wallet adapter into a wallet approval, chat, decision, evidence, connector, cloud workflow, and payments workspace. The public repo can explain the open-source pieces, but these drafts preserve the broader product and architecture story for selected reviewers.

Use these files for:

- founder, investor, partner, grant, accelerator, and interview reviews
- internal product positioning
- deciding what to publish later
- onboarding trusted collaborators

Do not put secrets here. Keep provider keys, private customer names, unreleased credentials, access tokens, and personal contact lists out of this folder.

## Drafts

- `public-readme-draft.md` - complete root README replacement draft.
- `docs-index-draft.md` - replacement draft for `docs/README.md`.

- `workflow-package-guide.md` - expanded guide for `packages/workflow`.
- `browser-app-guide.md` - expanded guide for `apps/browser-demo`.
- `render-cloud-guide.md` - Agentic Cloud and Render backend guide.
- `mcp-server-and-connectors.md` - MCP server and finance connector overview.
- `scenario-tests-private.md` - broader private scenario matrix.
- `ai-byok-and-agent-connectors.md` - AI route, BYOK, and subscription connector guide.
- `public-redaction-plan.md` - what can later move public and what should stay private.

## Sharing Rule

Share this folder as a private artifact, not as a committed repo path. If a public README update is needed, copy only the public-safe sections listed in `public-redaction-plan.md`.
