# Drift First-Class Connector Plan

## Goal

Replace Drift's current Blink-backed connector status with a first-class, narrowly scoped Drift adapter.

V1 scope is Drift account/vault visibility and vault deposit/withdraw lifecycle:

- Read Drift user/account facts.
- Read Drift vault facts.
- Prepare Drift vault deposit.
- Prepare Drift vault withdraw request.
- Prepare cancel withdraw request.
- Prepare complete withdraw after redeem period.

Do not include perp order placement, spot margin trading, leverage, Swift orders, or delegated accounts in v1.

## Current Repo State

Drift currently appears in:

- `apps/browser-demo/src/connectedDapps.ts`
- `packages/mcp-server/src/connectorRegistry.ts`
- `spec/connectors/drift.connector.json`
- `docs/connectors/planned-connectors.md`

Current runtime mode is planned/Blink-backed.

## External Source Of Truth

Use official Drift docs:

- Developer docs: https://docs.drift.trade/developers
- SDK internals: https://docs.drift.trade/developers/drift-sdk/sdk-internals
- Autogenerated SDK docs: https://docs.drift.trade/developers/drift-sdk/autogen

Key facts:

- Drift SDKs are used for trading apps, account/position reads, and transaction construction.
- TypeScript SDK package is `@drift-labs/sdk`.
- Drift SDK has account subscription and transaction construction layers.
- Drift docs separate Drift protocol trading, data API, vault managers, and automation.
- V1 must not expose perp trading because risk and product scope are materially larger.

## Dependencies

Shared runtime worker should add optional dependency:

- `@drift-labs/sdk`

If Drift vault-specific package is needed separately, shared worker should add it only after confirming official package naming and compatibility.

Adapter must dynamically import Drift packages and return `sdkUnavailable` if absent.

## Inputs

User snapshot:

- `walletAddress`: optional. Defaults to connected wallet.
- `subAccountId`: optional.

Vault snapshot:

- `vaultAddress`: required.

Wallet vault positions:

- `walletAddress`: optional. Defaults to connected wallet.
- `vaultAddress`: optional filter.

Vault deposit:

- `vaultAddress`: required.
- `amount`: required decimal string.
- `mint`: optional if vault defines one deposit mint.
- `initializeDepositorIfMissing`: optional boolean, default false.

Request withdraw:

- `vaultAddress`: required.
- `amount`: required or `shares`: required.
- `withdrawUnit`: enum `token | shares`, default `token`.

Cancel withdraw:

- `vaultAddress`: required.

Complete withdraw:

- `vaultAddress`: required.
- Must verify redeem period has elapsed or return needs-input/not-ready.

## Adapter Design

Files:

```text
packages/mcp-server/src/adapters/drift/constants.ts
packages/mcp-server/src/adapters/drift/client.ts
packages/mcp-server/src/adapters/drift/users.ts
packages/mcp-server/src/adapters/drift/vaults.ts
packages/mcp-server/src/adapters/drift/withdrawals.ts
packages/mcp-server/src/adapters/drift/index.ts
```

`client.ts`:

- Dynamic import Drift SDK.
- Build read-only wallet owner context.
- Configure env from `DRIFT_ENV` or mainnet-beta.
- Hide account subscription details behind stable helper methods.

`users.ts`:

- Read user account, subaccounts, deposits, borrows, health where available.
- Return read-only facts. No order placement.

`vaults.ts`:

- Read vault metadata, manager, deposit mint, total shares, user shares, redemption period, fees, lockups, and pending withdraw status.
- Build deposit transactions.

`withdrawals.ts`:

- Build request/cancel/complete withdraw transactions.
- Validate redeem period and pending request state.

- `refreshAtExecution: true`

Vault state must be refreshed before execution.

## Safety Checks

- Block all perp order placement in v1.
- Block delegated account operations in v1.
- Reject deposit if depositor initialization is required and not explicitly allowed.
- Reject complete withdraw before redeem period is done.
- Warn that vault strategies are manager-controlled.
- Warn on lockups, profit share, management fee, redeem period, and pending withdraw.
- Reject unknown vault program id.
- Do not batch request and complete withdrawal in one action.
