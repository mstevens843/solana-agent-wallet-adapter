# Colosseum Pitch Voiceover

Paste-ready voiceover script for `agentic-pitch-v20.mp4`. This version avoids a spoken category claim and frames Agentic as open-source, multi-wallet signing infrastructure for user-owned Solana actions.

## Recording Approach

- Use the 10 second selfie intro before the animation.
- Let the animation run without pausing.
- Read the timed voiceover below over the animation.
- Do not read the slide text word for word. The slides prove visually. The voiceover explains why it matters.
- Target pace: calm, direct, about 140 to 150 words per minute.

## Selfie Intro

```text
I'm Mathew Stevens.

I build Solana wallet infrastructure.

So I built Agentic: open-source signing infrastructure for AI agents on Solana.

Right now, agents are being handed private keys.

That works for agent-owned autonomy.

But for user-owned actions, the wallet should stay the signer.

Agentic flips the boundary.

Agents prepare. Your wallet signs.
```
