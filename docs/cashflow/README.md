# Operation Cash Flow

Date: 2026-06-09

This folder is the execution kit for selling short-term specialist services while job applications and app distribution continue in parallel.

## Target

Close or collect **$3k-$6k in 30 days** from specialist implementation work.

Primary positioning:

> I help Solana and AI-agent teams ship wallet, mobile, MCP, and production app integrations without handing private keys to agents or rebuilding their stack.

## Offer Stack

Publish these in this order:

1. **Solana Mobile Wallet Integration Sprint** - highest differentiation.
2. **MCP / AI Agent Tooling For Real Apps** - strongest current demand signal.
3. **Solana dApp Rescue / Wallet Bug Fix** - fastest diagnostic cash.
4. **Web-to-Mobile App Shipping Sprint** - broadest buyer pool, still proof-backed.

Use [service-offers.md](./service-offers.md) as the source of truth for pricing, scope, proof points, and qualifying rules.

## Channel Order

1. **Direct outbound** - 15-25 targeted messages per day for 10 days.
2. **Upwork** - 8-12 proposals per day, only on jobs matching the filters in [upwork.md](./upwork.md).
3. **Fiverr** - publish specialist gigs as inbound capture, not as the primary pipeline.
4. **Contra** - publish a clean services page and use it for direct-client credibility/payment.
5. **Superteam Earn/Talent** - check daily, but only do paid projects or pre-approved scopes.

Start with [target-leads.md](./target-leads.md) for the first Solana Mobile / Seeker outbound batch.

## Daily Operating Loop

Morning:

- Check Upwork searches: `Solana wallet`, `MCP server`, `AI integration`, `wallet integration`, `React Native crypto wallet`, `Next.js Solana`, `dApp bug`, `Jupiter API`, `mobile app deployment`.
- Send 8-12 Upwork proposals using [upwork.md](./upwork.md).
- Send 15 direct messages using [direct-outbound.md](./direct-outbound.md).

Afternoon:

- Follow up on every reply within 2 hours.
- Push qualified prospects toward a paid diagnostic or 20-minute call.
- Update [pipeline.csv](./pipeline.csv).

Evening:

- Send second batch of direct messages if daily target is not met.
- Review replies and tune hooks without changing the core offer.

## Close Path

Default sequence:

1. Free short reply or call to confirm fit.
2. Paid diagnostic: $250-$500.
3. Fixed implementation sprint: $750-$3,500.
4. Production hardening or retainer: $1,500-$6,000.

Do not accept unpaid implementation, speculative grants, or bounty work unless payment eligibility is confirmed in writing before work begins.
