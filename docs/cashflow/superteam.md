# Superteam / Crypto-Native Rules

Superteam is a good fit for Solana-native visibility, but it is not the first cash-flow channel unless the listing is a paid project or payment eligibility is confirmed.

## Daily Check

Search:

- Development
- Frontend
- Solana Mobile
- Wallet
- Agentic
- MCP
- Game
- Android
- iOS
- SDK

## Apply To

- Paid projects where one selected builder completes the work.
- Jobs or contract roles.
- Grants where eligibility is clear and pre-approval is explicit.
- Bounties only when the work is small, already aligned with current roadmap, and not speculative.

## Do Not Start Work Until

You have written confirmation for:

- Eligibility.
- Scope.
- Payment amount.
- Judging/approval path.
- Whether prior work or merged PRs qualify.
- Whether another team has already been pre-approved.

## Pre-Approval Message

```text
Hi [name] - I am interested in this Solana Mobile / wallet / SDK scope.

Before I start implementation, can you confirm:
1. Am I eligible to be paid for this listing?
2. Is the winner/contractor selected before work starts, or is this a competitive bounty?
3. Has another team already been pre-approved for this exact scope?
4. If I submit PRs and they merge, does that qualify for payment?
5. Who gives final approval and what is the expected payout timeline?

I ask because I have previously had relevant Solana Mobile PRs merged but was told payment required pre-approval after the fact. I want to avoid creating a situation where the work is complete but no one can be paid.

Relevant proof: https://mathewstevens.dev/portfolio/
```
